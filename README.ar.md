## ضقنا ذرعًا بـ Anthropic

باعتبارنا مستخدمين عاديين يريدون فقط التحدث والتعاون مع Claude، فقد سئمنا تكوين مثيلات VPS وملفات تعريف بصمات المتصفح والتحقق من البيئة، بينما نشعر بالقلق بشأن حظر الحسابات والخسائر المالية. نحن نقدم **Claude 防封** — **تطبيق سطح مكتب جاهز للاستخدام: قم بتكوين وكيل الشبكة الخاص بك وإدارة عمليات التحقق من البيئة المعزولة والمنطقة الزمنية واللغة والبيئة في مكان واحد.**

Claude 防封 عبارة عن جهاز Linux افتراضي خفيف الوزن يجمع بين محطة Linux والمتصفح ومحرر الملفات في تطبيق سطح مكتب واحد. وتشمل ميزاته الرئيسية ما يلي:

- إعدادات الشبكة معزولة عن المضيف؛ يقوم Cage بتوجيه كل حركة مرور الشبكة داخل بيئته من خلال وكيل الشبكة الخاص به
- إعدادات بصمة المتصفح معزولة عن المضيف، بما في ذلك المنطقة الزمنية واللغة، مع مزامنة تلقائية لموقع IP الخاص بوكيل الشبكة
- التكامل خلال سير عمل Claude: تسجيل الدخول في المتصفح، وتخويل الحساب، وعملية Claude Code
- تعمل فحوصات الشبكة والعزل المضمنة على إيقاف الوصول إلى الإنترنت عند فشل عمليات التحقق المهمة أو عدم اكتمال الأدلة؛ توفر فحوصات المجتمع والأطراف الثالثة معلومات مرجعية إضافية

## ما يمكنك فعله مع كيج

- **العمل في نافذة واحدة.** قم بتشغيل Claude Code في الجهاز، وراجع التغييرات في المحرر، واستخدم متصفح Cage لمعاينة الخدمات وتسجيل الدخول.
- **السيطرة على ما تشاركه.** تتم مشاركة مساحة العمل الافتراضية ومجلدات المشروع المفتوحة بشكل صريح فقط. لا يتم استيراد حالة تسجيل دخول Claude للمضيف وملفات تعريف المتصفح ومفاتيح SSH تلقائيًا.
- **انظر حالة الشبكة الخاصة بك.** تتيح لك إدارة وكيل الشبكة المضمنة استيراد الاشتراكات وتحديد نقاط النهاية والتحقق من عنوان IP الخاص بالخروج. تظل البيئة غير متصلة بالإنترنت حتى تمر عمليات التحقق المهمة. إذا كان وكيل الشبكة غير متوفر، فلا يمكن الرجوع إلى الاتصال المباشر.
- **استمر في المرة القادمة.** تستمر الأدوات والملفات وحالة تسجيل الدخول على القرص الظاهري. يمكن أن تستمر مهام الخلفية في العمل عند إغلاق النافذة.
- **إدارة عدة حسابات Claude Code.** يُخصَّص حساب لكل طرفية Claude جديدة، ويمكن عرض حصص الاستخدام لخمس ساعات وسبعة أيام. لا تتغير حسابات الطرفيات الجاري تشغيلها تلقائيًا.
- **متابعة العمل من الهاتف.** يتصل عميل الهاتف التطويري بالكمبيوتر لجلسات CLI المنظَّمة والموافقة على الأدوات؛ ويتطلب المتصفح البعيد إذنًا منفصلًا. يجب بناء عميل الهاتف من المصدر، ولا يتيح التحكم في أي طرفية عادية موجودة.
- **تشغيل Cage في السحابة.** اتصل عبر SSH ببيئة Cage المنشورة على VPS متوافق يعمل بنظام Linux x86_64، دون الحاجة إلى KVM. تبقى البيانات ومخرج الشبكة على الخادم.

## بداية سريعة

أرسل هذا الطلب إلى وكيل الذكاء الاصطناعي لديك (codex، dsh، Workbuddy - ربما ليس Claude Code 😁):

```markdown
ساعدني في التثبيت https://github.com/tan396222-prog/Claude-AntiBan وقم بتكوين وكيل شبكة Cage لاستخدام نقطة النهاية xxx في تثبيت Clash المحلي الخاص بي.
```

كل ما تحتاجه هو نقطة نهاية وكيل شبكة موثوقة. لا يروج هذا المشروع لأي مزود وكيل؛ يمكنك العثور على مقدم الخدمة بنفسك، على سبيل المثال من خلال البحث عن موقع Black Error على الويب.

## التنزيل والتثبيت

يدعم Cage أنظمة macOS وWindows وLinux: أجهزة Apple Silicon مع macOS 14+، وWindows 10 22H2 / 11 x64، وDebian 12 / Ubuntu 24.04 x86_64. لا يزال Windows وLinux قيد التحقق. راجع ملاحظات الإصدار لتوفر الحزم والتوقيعات والاختبارات الفعلية. لا تُدعم حاليًا أجهزة Intel Mac أو Windows ARM64 أو Linux ARM64. [macOS](docs/getting-started.md) · [Windows](docs/windows.md) · [Linux](docs/linux.md).

1. تنزيل التطبيق: [macOS / Windows / Linux](https://github.com/tan396222-prog/Claude-AntiBan/releases).
2. macOS: افتح حزمة التثبيت واسحب **Cage** في **التطبيقات**; ثم قم بتشغيله من التطبيقات. Windows: [دليل التثبيت](docs/windows.md#安装并开始工作) · Linux: [دليل التثبيت](docs/linux.md#安装并开始工作).
3. اتبع الإرشادات الموجودة في التطبيق لتكوين وكيل الشبكة الخاص بك، وبدء تشغيل البيئة، وفتح المشروع.

يشتمل برنامج التثبيت على منضدة العمل ونواة وكيل الشبكة. لا يتطلب الاستخدام اليومي تثبيت Go أو Node.js أو Docker أو Clash. لا يزال الإطلاق الأول يتطلب اتصالاً بالإنترنت لتنزيل صورة Linux وأدوات التطوير. لا يوفر Cage خدمة وكيل الشبكة ولا حساب Claude.

راجع [Releases](https://github.com/tan396222-prog/Claude-AntiBan/releases) لمعرفة الإصدارات العامة المتاحة. كود المصدر والموقع الإلكتروني والإصدارات عامة. راجع ملاحظات كل إصدار لتوقيع المثبت وتوثيق Apple ونطاق التحقق من الصحة. لا يزال التثبيت النظيف للجهاز، والتوافق على أجهزة Mac الفعلية التي تعمل بنظام macOS 14، والترخيص الحقيقي لحساب Claude، وطلبات النماذج تتطلب التحقق الكامل من الصحة.

تُنزّل تحديثات macOS وWindows عبر الوكيل المختار دون اتصال مباشر احتياطي. احفظ العمل وأوقف المهام قبل التثبيت. يتطلب macOS توقيع Developer ID من الناشر نفسه والتحقق من Apple؛ ويتطلب Windows توقيع Authenticode موثوقًا ومفتاح الناشر العام نفسه. تُحدّث نسخة Windows التجريبية غير الموقعة وحزم Linux يدويًا. [التحديث وإلغاء التثبيت](docs/getting-started.md#升级与卸载).

## ابدأ في ثلاث خطوات

### 1. حدد وكيل الشبكة

في الصفحة الرئيسية، انقر فوق "تكوين الشبكة والوكيل"، ثم "إضافة مصدر". قم باستيراد اشتراك Clash/Mihomo YAML أو ملف YAML محلي، وحدد نقطة نهاية ضمن "العقد". في حالة عدم توفر وكيل شبكة، يمكنك تحديد "تنزيل هذا الاشتراك من خلال الشبكة المضيفة" بشكل صريح، أو استيراد ملف محلي مباشرةً. لاحقًا، قم بإدارة نقاط النهاية ضمن "الإعدادات → الشبكة والوكيل".

### 2. ابدأ البيئة

ارجع إلى طاولة العمل وانقر على "بدء بيئة القفص". إذا كان إعداد Git الخاص بالمضيف يحتاج إلى حماية أمنية، فسيقوم التطبيق أولاً بشرح التأثيرات. قم بتطبيقه بالنقر فوق "تمكين الحماية والمتابعة". الالتزامات والسحب للمشاريع العادية لا تتأثر. يقوم Cage بعد ذلك بتنزيل الصورة وتثبيت الأدوات وتشغيل عمليات فحص الشبكة. عرض التقدم ضمن "تفاصيل العملية". بمجرد أن تصبح البيئة جاهزة وتم اجتياز الاختبارات المهمة، يمكنك العمل عبر الإنترنت. إذا فشلت عملية التحقق، فاتبع الإرشادات لإصلاح المشكلة ثم أعد المحاولة.

### 3. افتح مشروعًا وقم بتشغيل كلود

انقر فوق "فتح المشروع" لتحديد مجلد على جهاز الكمبيوتر الخاص بك، وافتح محطة جديدة، ثم أدخل `claude`; ثم قم بتفويض حسابك الخاص في متصفح Cage. يمكنك أيضًا البدء بمساحة العمل الافتراضية دون إعداد مشروع. للحصول على الخطوات الكاملة، راجع [البدء](docs/getting-started.md).

## افهم هذه الحدود قبل الاستخدام

- تؤثر عمليات التحرير والحذف في المشاريع المشتركة بشكل مباشر على الملفات الموجودة على جهاز الكمبيوتر الخاص بك. استخدم التحكم في الإصدار أو النسخ الاحتياطية. `.git` وتكون البيانات الوصفية الأخرى للقراءة فقط بشكل افتراضي؛ جعل Git يلتزم على جهاز الكمبيوتر.
- تشترك جميع المشاريع في بيئة Cage واحدة، بما في ذلك أدواتها وحساباتها ونظام ملفات Linux. المشاريع ليست معزولة عن بعضها البعض.
- يتمتع الضيف حاليًا بإمكانية الوصول إلى IPv4 TCP العام من خلال وكيل الشبكة، مع إرسال DNS عبر نفس الوكيل. يتم حظر اتصالات UDP وIPv6 وICMP العامة والاتصالات التي يبدأها الضيف بالمضيف أو الشبكة المحلية. قد لا تعمل الأدوات التي تعتمد على هذه القدرات.
- تُظهر عمليات فحص الشبكة التكوين الحالي والأدلة التي تم أخذ عينات منها. ولا يمكنها ضمان أن الحساب سوف يتجنب قيود النظام الأساسي، ولا تحل محل تدقيق أمان المحاكاة الافتراضية الكامل.

لمزيد من التفاصيل، انظر [حدود الشبكة والبيانات](docs/getting-started.md#网络与数据边界), [تصميم فحص الشبكة](docs/design/network-checks.md) و [تصميم وكيل الشبكة المدمج](docs/design/managed-proxy.md).
