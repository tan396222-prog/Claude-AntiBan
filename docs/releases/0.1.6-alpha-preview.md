# Cage v0.1.6-alpha-preview

从工作台侧栏的「SSH 主机」可以连接云端 Cage，文件、项目和网络都在所选服务器上。首次部署时核对主机指纹，点击「部署并连接」后，服务器从 Debian 基础镜像安装环境。服务已停止时，重连会启动服务。支持配置了 systemd 用户服务、cgroup v2 和 rootless 容器所需权限的 Linux x86_64 VPS，无需 KVM。

打开 Cage 仍默认进入本机工作台。连接服务器无需先启动本机虚拟机。本机有任务时可以选择继续运行，或在切换前停止它以释放内存。

- 支持选择环境存储位置，改进持久磁盘路径、可用空间检查和迁移。首次安装会显示下载与准备进度，修复弱网下的组件获取和重试。
- 修复 Windows 虚拟机固件查找和 WHPX CPU 配置，改进 Linux 安装依赖检测。
- 改进浏览器开发者工具、下载处理与网络恢复。新的网络授权生效后会清除已解决的监测错误。

macOS 安装包适用于 Apple Silicon。Windows x64 提供需手动安装的未签名预览包。Linux x86_64 使用 DEB 安装或更新。升级前请保存工作并退出 Cage。
