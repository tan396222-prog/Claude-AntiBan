# Cage v0.1.7-rc.1

本次为 Cage 首轮 RC 发行，相较 `v0.1.6-alpha-preview`，重点完善多系统客机、首次初始化、私网设备连接、项目恢复与文件交互。版本号中的 `rc.1` 表示发布候选版，仍可能存在兼容性问题。请保留原有配置与虚拟磁盘，使用安装器或应用内更新升级。

## Tailscale：登录后查看并使用私网设备

- 点击“连接并登录”，在官方页面完成授权，再回到面板即可看到账号、网络、当前 Cage 地址和其他设备。
- 设备清单支持搜索名称、系统或地址，在线设备优先；未登录、等待管理员审批、网络为空和连接失败分别给出下一步提示。
- 按设备使用 SSH，或为 Web、数据库等 TCP 服务创建 Cage 内可用的本地连接地址。支持 HTTP 代理的应用也可通过私网代理使用设备域名、HTTP 和 HTTPS。
- SSH 公钥配置按需展开，避免把加入私网与远程终端认证混在一起。登录页打开失败、公钥错误及服务地址创建失败可以直接重试。
- 断开会关闭已有私网连接与服务映射，保留设备身份和 SSH 公钥。私网外层通信继续遵循 Cage 的受控公网出口与暂停联网规则。

这一接入方式使用内嵌节点：SSH 自动配置传输，其他应用使用服务连接地址或 HTTP 代理。整机透明 VPN、UDP、子网路由和出口节点未启用；不会接管宿主机 Tailscale。

## 首次使用与多系统环境

- 首次初始化统一选择客机系统、环境存储位置和代理，支持受管镜像下载及创建进度反馈。
- 支持 macOS、Windows 11 与 Linux 客机的创建、组件置备和工作台接入；可按受支持的主机系统选择相应镜像。
- Cage 账户设置与 macOS 客机账户同步，补齐客机登录、密码维护和权限恢复入口。
- CPU、内存等资源设置集中管理，可直接修改并恢复默认值；环境与个人配置使用稳定路径。
- 系统镜像下载遵循主机现有代理，减少首次下载路径与日常 Cage 网络配置之间的混淆。

## 项目、存储和恢复

- 默认工作区与配置目录分离，保留旧环境身份，避免升级后误建一套新的虚拟磁盘。
- 环境存储迁移保持账户、配置、登录状态和持久虚拟磁盘；迁移前备份继续保留。
- 外置存储不可用或迁移未完成时，工作台提供恢复入口，恢复前阻止误启动；Windows 可修复系统助手后继续恢复。
- macOS 项目共享遇到登录、文件共享、屏幕录制或辅助功能权限问题时，提供对应的恢复操作，并在恢复后重新检查项目连接。
- Windows 的虚拟磁盘复制、注册与系统助手绑定流程同步完善，避免文件属性或旧路径影响磁盘重新挂载。
- 项目选择窗口支持移除已关联项目并撤销目录共享，原文件和会话历史保留。移除前核对终端、会话和编辑器的使用状态，默认工作区继续保留。

## 日常交互与跨设备协作

- 工作台终端与远程桌面支持 `Shift+Enter` 换行，普通回车继续提交；修复焦点切换后 Shift 状态丢失，并保持粘贴与后续按键的顺序。目标输入框或终端程序需要支持多行输入，输入法候选确认仍由输入法处理。
- 会话列表会提前显示其他窗口正在运行的会话及占用原因，结束后自动恢复可点击；打开一个会话时，其他会话仍可独立操作。
- Desktop 窗口隐藏后暂停状态轮询，恢复可见时重新读取；多个查看者共享短时状态结果，减少重复探测和慢请求重叠。
- Linux 客机中的 Desktop 在最后一个查看者离开后自动隐藏窗口，减少后台绘图，应用和命令继续运行；电脑或手机重新查看时恢复原窗口。
- 完善文本、图片和文件剪贴板的请求绑定、缓存归属和失效处理，减少切换窗口后粘贴到旧目标或复制到旧内容的问题。
- 完善浏览器与客机桌面的下载、保存和文件打开确认，失败后保留可重试的入口。
- 改善 macOS 客机授权与登录窗口的操作反馈；Windows 标题栏和菜单跟随工作台主题。
- Windows 后台命令静默运行，工作台失联时仍可退出本地应用。Linux 工作台的原生消息接口在页面存续期间保持可用。
- 更新浏览器设置、工作台、标签与项目入口，并统一电脑／手机的配对传输和会话链路。
- 完善 Claude Code 多账号、会话额度和账号标识的呈现，以及远端工作台和原生客机的功能衔接。

## 安装、更新与维护

- Windows 发行安装器接入可信云签名，更新时继续验证 Authenticode 信任链与发布者身份；macOS 发行物使用 Developer ID 签名与 Apple 公证。
- 补齐安装、更新失败恢复及重试；升级与卸载管理应用文件，保留用户个人数据。
- 完善代理订阅兼容、出口地区策略、连接恢复、诊断脱敏、资源探测与配置并发处理。
- 导入旧 WebSocket 订阅时转换路径和请求头字段，确保实际连接使用这些配置；双栈代理节点的出口检查明确检测 IPv4 地址。
- 运行记录核对进程身份，避免系统复用进程编号后把旧环境误判为仍在运行。
- 提供供外部 Agent 使用的配置、诊断与原生操作入口，并校验下载安装包。
- 同步使用文档和下载入口，保留必要构建源码、依赖与许可材料；开发计划、研究和 QA 记录留在本地。

## 支持范围与升级注意

- macOS 主机：Apple Silicon、macOS 14 及以上。
- Windows 主机：Windows 10 22H2／11 x64；Windows 11 客机需要支持 Hyper-V 的 Windows 11 专业版、企业版或教育版主机。
- Linux 主机：Debian 12、Ubuntu 22.04／24.04 x86_64。Intel Mac、Windows ARM64 和 Linux ARM64 主机暂不支持。
- 使用旧版未签名 Windows 预览包的用户，需要手动下载并安装本版可信签名安装器一次，之后才能使用签名校验的自动更新。
- 新增或更新原生客机能力后，请按工作台提示同步环境组件。不要删除 `.claude-cage`、旧环境磁盘或迁移备份来解决升级问题。
- 真实账号授权、特定主机权限、音频设备、显示缩放、第三方输入法以及手机网络环境仍可能有差异。自动化、构建及隔离网络测试不等于所有设备组合的实机验收。

完整使用说明见 [Cage 使用文档](../README.md)。本版本公开安装包、校验清单与对应源码以本发行条目的附件为准。
