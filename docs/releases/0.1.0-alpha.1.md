# Cage 0.1.0-alpha.1

这是 Cage 面向内测团队的首个版本，支持 Apple Silicon Mac 与 macOS 14 或更新版本。它把 Linux 终端、浏览器和文件编辑器放在同一个桌面工作区中，网络由 Cage 自己的受管代理接管。

## 安装与开始使用

从[本版本 Release](https://github.com/tan396222-prog/Claude-AntiBan/releases/tag/v0.1.0-alpha.1) 下载 `Cage-0.1.0-alpha.1-macos-arm64.dmg`，将 Cage 拖入 Applications，再从应用程序打开。配置自己的 Clash / Mihomo YAML 或订阅，选择节点后启动环境。首次启动会下载 Linux 镜像与开发工具。

代理服务和 Claude 账户或授权需要自行准备。打开演示或测试项目，在终端输入 `claude`，并在 Cage 浏览器中完成自己的账户授权。完整步骤见[开始使用](../getting-started.md)。

后续发布新版本时，可在应用内检查、下载、校验、安装并重启。下载经过所选受管代理，没有主机直连回退；新包须由同一 Apple 发布者签名并通过校验。有运行任务时，先保存并确认停止；应用替换保留项目、代理配置和虚拟磁盘。

## 本版能力

- 工作区集成项目与终端列表、浏览器标签、收藏和下载管理。
- 支持 Mac 快捷键、中文输入和文本剪贴板；窗口隐藏时停止浏览器画面传输，保留页面与任务。
- 网络与隔离检查控制外网放行；人工暂停可持久保存，订阅刷新和后台重启不会自动解除暂停。
- 编辑器可独立恢复；下载保存失败保留重试信息，同名文件不覆盖。
- 控制服务按版本和程序身份管理后台，环境设置可查看组件与工具版本。
- 主页与 README 共用产品内容和 15 种语言，默认中文，通过下拉框切换。

## 发布验收

本版本的 App 与 DMG 均已通过 Developer ID 签名、Apple 公证、票据附加和 Gatekeeper 验证。最终控制程序在独立空配置下启动，确认版本为 `0.1.0-alpha.1`；真实内置浏览器已打开 Claude 新对话页，原生窗口显示正常。

源码验证覆盖 Go 回归、相关竞态检查与 vet、前端 lint 与单元测试、浏览器和文件操作、更新器、第三方补丁与依赖许可。安装包与对应 Mihomo 源码随附 `SHA256SUMS`，公开发行工作流会下载附件并再次验证摘要、签名、公证和应用版本。

## 内测范围与限制

请先使用有备份的测试项目。共享目录的修改、删除会直接影响 Mac；同一环境中的项目共享账户、工具和文件系统。

以下仍需真实使用验收：全新实体 Mac 的镜像下载与完整安装、macOS 14 实机兼容性、真实 Claude 授权和模型请求，以及两个正式签名版本之间的原生自动替换、系统安装授权、重启与回滚整链路。单元测试与公证结果不代替这些验收。

网络检查反映当时配置与采样证据，无法保证账户不会受到平台限制。
