# Cage v0.1.5-alpha.2

代理设置可以直接组合中转与最终出口，无需编辑 YAML。选择链式代理后，节点按实际连接顺序排列，并显示目标网站看到的最终出口；支持跨订阅组合。配置完成后统一应用，订阅更新保留组合，失败时保留可重试的草稿。

本版本还包含以下改进：

- 将 IP 变化规则并入网络与代理页面，网络检查中的出口规则入口也指向同一位置；完善帮助、内嵌选择及未应用修改的离开提示。
- 代理与状态栏统一 HTTP 往返延迟口径，说明通常不含建连开销，与网页首开耗时区分。
- 调整代理连接与加密 DNS 的超时处理，在当前代理内重试，不回退主机直连。
- 环境准备失败后可以利用已有文件重试；镜像与工具下载支持经过摘要验证的缓存和续传，工具安装避免重复下载。
- 更新宣传片源码、横竖版界面素材与社交配图。

## 安装与更新

macOS 提供 Apple Silicon、macOS 14 或更新版本的 Developer ID 签名、公证 DMG。Windows 沿用 x64 未签名预览安装器，需要手动安装和更新，不进入签名自动更新通道。Linux 提供 Debian 12 / Ubuntu 24.04 x86_64 DEB，使用系统包管理器安装和更新。

升级前保存文件、停止环境并退出 Cage。账户、订阅、收藏、项目和持久虚拟机数据保留。三平台附件共用 SHA256SUMS，同时提供 Mihomo 与 QEMU 主程序对应源码。

## 验证范围

本地通过完整 Go 测试、相关 race 检查、前端 lint / 50 项测试 / 构建、48 项发布流程测试。真实控制服务与随附 Mihomo 验证了本地双跳、单节点切换和出口故障时没有直连回退；界面验证跨来源选择、键盘操作、草稿保留、失败重试、离开确认和窄屏。macOS 更新器验证签名、失败回滚和数据保留，本机安装后原账户与关键数据保留。

公开发行前，还须在对应提交完成三平台 CI、macOS 最终 DMG 的签名公证与匿名下载验证，并通过官网检查。实际完成情况与源码提交记录在本次 GitHub Release 中；未完成的项目不能据本说明视为通过。真实住宅节点、公网 Claude 请求、全新 Mac 首次启动、Windows 10/11 和 Linux/KVM 桌面仍需实机验收。
